# HW2: Learn Git Branching

## Process

I worked through the Introduction, Ramping Up, and Push & Pull --
Git Remotes! sequences in Learn Git Branching.

For each level, I read the instructions and compared the starting
commit graph with the target graph. I identified which commits,
branches, and HEAD positions needed to change, then entered Git
commands in the game terminal.

When a command did not produce the expected result, I checked the
updated graph and revised my approach. 

## AI assistance

I used ChatGPT to explain Git commands and concepts and to help with levels where I got stuck or did not pass.
