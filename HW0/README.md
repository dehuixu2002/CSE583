HW0: Bash Scripting
I used Nano in my Mac terminal to write download_pronto.bash. The script creates a pronto directory, writes a description of the dataset to pronto/README.txt, and creates a pronto/data subdirectory. It uses curl to download the Pronto dataset into the data directory, unzip to extract it, and head to display the first five lines of 2015_trip_data.csv.
